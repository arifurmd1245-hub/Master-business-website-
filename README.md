# Universal Professional Business Website System

This repository contains a production-ready, mobile-first, universal business website system built strictly according to the Ultimate Master Prompt specification.

## Features
- **Configurable Customer Website:** Responsive UI, dynamic product listing, item variants, cart checkout, and printable invoice memo.
- **Admin Control Panel:** Integrated dashboard to add/delete products/services, view customer orders, and manage business details & delivery fees.
- **Zero-Dependency Hosting:** Native HTML5, CSS3 (Tailwind CSS), and Vanilla JavaScript. Works instantly on GitHub Pages, Vercel, Netlify, Cloudflare Pages, or traditional cPanel servers.

## How to Deploy on GitHub Pages
1. Create a new repository on GitHub.
2. Push all extracted files (`index.html`, `css/`, `js/`, `vercel.json`, `README.md`) to the `main` branch.
3. Go to **Settings > Pages** in your GitHub repository.
4. Set source to `Deploy from a branch` and select `main` / `root`.
5. Click Save. Your website will be live in 1 minute!

## How to Deploy on Vercel or Netlify
Simply drag and drop this unzipped folder or link your GitHub repository directly. No build commands required.
